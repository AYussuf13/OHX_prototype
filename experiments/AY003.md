# AY003: Sensor Stabilisation and Baseline Characterisation Experiment

## Objective

To determine the warm-up period of the BME688 gas sensor and identify when the baseline gas resistance reaches a stable plateau suitable for breath measurements.

## Research Question

How long does the BME688 sensor require after activation before baseline measurements become stable?

## Experimental Setup

### Hardware
- ESP32 microcontroller
- BME688 gas sensor
- TFT display

### Software
- Arduino firmware
- Python data logging pipeline
- CSV data storage
- Matplotlib visualisation

The sensor was operated under normal environmental conditions without breath exposure to characterise natural baseline behaviour.

## Method

1. The BME688 sensor was powered on.
2. Baseline gas resistance measurements were continuously recorded for approximately 45 minutes.
3. Sensor output was logged over time and stored as CSV files.
4. Three independent baseline experiments were analysed.
5. Gas resistance drift was calculated as:

\[
\Delta R / \Delta t
\]

6. The drift signal was smoothed using a rolling average.
7. The final 20% of each experiment was used to estimate steady-state sensor behaviour.
8. Warm-up time was defined as the point where the sensor drift entered the stable operating range.

## Observations

### Initial Baseline Drift

Following activation, the sensor exhibited significant changes in gas resistance over time.

This initial variation represents the sensor warm-up period and equilibration before reaching a steady operating state.

### Stabilisation Phase

After the initial drift period, the rate of gas resistance change decreased and approached a stable baseline region.

A mathematical analysis was used to identify the settling point rather than relying only on visual inspection of the plateau.

## Results

Three baseline experiments were analysed:

| Experiment | Calculated Warm-up Time |
|---|---|
| Run 1 | 15.97 minutes |
| Run 2 | 18.17 minutes |
| Run 3 | 11.01 minutes |

Average warm-up time:

**15.05 ± 3.00 minutes**

The stable drift thresholds calculated from each experiment were:

- Run 1: 0.544 kΩ/min
- Run 2: 0.307 kΩ/min
- Run 3: 0.637 kΩ/min

## Conclusion

The BME688 sensor reached a stable baseline after approximately 15 minutes under the tested conditions.

Due to variation between experiments, a conservative warm-up period of approximately 20 minutes will be used before future OHX breath measurements.

## Impact on OHX Development

Characterising sensor stabilisation is essential for reliable breath data collection.

The results define a standard operating procedure for future experiments by ensuring breath measurements are collected only after the sensor has reached a stable baseline.

## Next Steps
- Investigate environmental effects (temperature/humidity) on baseline drift.
- Begin structured breath exposure experiments using the defined warm-up protocol.
