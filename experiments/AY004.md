# AY004: Breath Response Characterisation

## Overview

AY004 focused on developing the data analysis pipeline for OHX breath measurements using the BME688 gas sensor.

The aim was to move from raw sensor output to structured breath-response features that can support future personalised longitudinal monitoring.

---

## What was done

During this experiment:

- Repeated breath events were collected using the OHX prototype
- Raw sensor output was recorded as CSV data
- A Python analysis pipeline was developed to identify individual breath responses
- Sensor features were extracted from each breath event

---

## Data Processing

The analysis pipeline converts raw sensor measurements into response features including:

- Pre-breath baseline
- Minimum sensor response following exposure
- Percentage change from baseline
- Recovery behaviour

This enables repeated measurements to be compared across future sessions.

---

## Key Progress

This experiment established the first version of the OHX breath-response analysis workflow.

The system can now:

✅ Collect breath-response data  
✅ Process raw sensor recordings  
✅ Identify individual breath events  
✅ Generate structured response profiles  

---

## Next Steps

Future experiments will focus on:

- Improving breath collection standardisation
- Collecting longitudinal sessions over time
- Comparing measurements against individual baselines
- Developing automated detection and machine learning approaches

---

## Significance

AY004 represents a transition from sensor prototyping towards data-driven personalised monitoring.

The goal is to build a system capable of learning individual response patterns over time.
