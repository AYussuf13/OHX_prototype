# OHX

## Breath-based monitoring for longitudinal oncology insights

OHX is an early-stage medtech startup exploring whether breath-based VOC sensing can provide additional insights into cancer treatment monitoring.

## The Problem

Current approaches to monitoring cancer treatment response can rely on imaging and clinical assessments, which may not always capture biological changes as early as possible.

OHX explores the potential of non-invasive breath analysis as a complementary monitoring approach.

## Development Vision

The initial goal of OHX is to develop a low-cost breath sensing platform capable of capturing and learning patterns from breath-derived signals.

The current prototype focuses on validating the feasibility of breath sampling, sensor response, and data acquisition.

Future development will investigate whether machine learning approaches can identify meaningful patterns within breath signals and whether these patterns could support future applications in longitudinal health monitoring, including oncology.

## Current Prototype

The current proof-of-concept includes:

- ESP32 microcontroller
- BME688 gas sensor
- Custom breath sampling setup
- Real-time sensor data collection

## Progress

- Built initial hardware prototype  
- Developed a breath sampling setup  
- Achieved sensor response to breath exposure  
- Implemented baseline calibration and sensor logging  
- Began early clinical discovery conversations

## Next Steps

- Improve breath sampling consistency
- Collect and analyse more sensor response data
- Explore VOC pattern recognition approaches
- Develop the prototype further during MSc Biomedical Engineering

## Disclaimer

This is an early-stage research prototype and is not yet a medical device or diagnostic tool.
